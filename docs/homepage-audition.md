# Homepage Audition — the Rubric

Every buddy homepage is judged against this rubric. A page that fails a
criterion isn't finished.

1. **Identity.** The buddy's icon, name, and one-line brief are unmistakable
   at a glance. A sticky header keeps the buddy's name on screen while
   scrolling.
2. **Mission.** What this buddy is for, in the owner's words, near the top.
3. **Status.** What it's working on now, what's next, and what's blocked —
   current, not aspirational.
4. **Attention with actions.** Every open item appears with its full action
   set on the item itself: ✓ Done / Need more info / Later / Drop it, with
   Undo, plus ✎ Add a note… (opens a field on the card; the note saves
   through the token-gated ingest path and shows on the card). Dispositions
   persist as registry stamps; dispositioned items stay visible with their
   stamp and leave the open counts.
5. **Files.** A Files section listing the documents the buddy manages —
   contents readable in place, unless the buddy is `private_files` (names
   only).
6. **Family.** Parent and children are linked; you can walk the tree from
   any page.
7. **Brain-dump box.** A way to hand the buddy a note, a link, or a file
   from the page itself.
8. **Tip jar.** The canonical jar (docs/tipjar-snippet.html) in the header.
9. **Dark mode.** Fully readable in dark and light, following the device's
   `prefers-color-scheme`.
10. **Phone-first.** The page works one-handed on a phone: tap targets,
    no horizontal scroll, nothing essential below a long scroll.

## Scorecard

| # | Criterion | Pass looks like |
|---|---|---|
| 1 | Identity | Icon + name + brief above the fold; sticky header |
| 2 | Mission | Owner's words, top of page |
| 3 | Status | Current work, next step, blockers |
| 4 | Attention actions | Full set on every item, stamps persist, Undo works |
| 5 | Files | Section present; contents open in place (or private_files) |
| 6 | Family | Parent crumb + children links |
| 7 | Brain-dump | Box present and wired to the buddy's ingest |
| 8 | Tip jar | Header placement, canonical snippet |
| 9 | Dark mode | Both schemes verified |
| 10 | Phone-first | Verified at phone width |
